# Model Information

## AnimeGANv2
- **Paper**: AnimeGANv2: The Improved Version of AnimeGAN
- **Original**: https://github.com/TachibanaYoshino/AnimeGANv2
- **PyTorch Implementation**: https://github.com/bryandlee/animegan2-pytorch
- **License**: See original repository (non-commercial academic use)
- **Variants**:
  - `paprika` — General landscape/scenery (recommended)
  - `celeba_distill` — Face style
  - `face_paint_512_v1` — Face portrait v1
  - `face_paint_512_v2` — Face portrait v2 (more robust)

## White-box Cartoonization
- **Paper**: Learning to Cartoonize Using White-box Cartoon Representations (CVPR 2020)
- **Original**: https://github.com/SystemErrorWang/White-box-Cartoonization
- **HuggingFace Model**: https://huggingface.co/sayakpaul/whitebox-cartoonizer
- **Framework**: TensorFlow 2 SavedModel
- **Best for**: Scenery, general images
